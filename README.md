# Mini Catalog

Каталог товаров с карточками, подробной страницей товара и корзиной.

## Возможности

- Каталог и навигация между страницами.
- Корзина и пользовательские действия.
- API-адаптер, преобразование DTO и тесты интерфейса.

## Инженерные акценты

- Разделение транспорта, моделей данных и представления.
- Реализация связанного покупательского сценария.
- Управление состоянием через Zustand и проверка компонентов.

## Стек

React, TypeScript, Zustand, Tailwind CSS, Vite, Vitest.

## Навигация по коду

- [src/](src/) — исходный код.

```sh
pnpm install
pnpm dev
pnpm test
pnpm build
pnpm lint
```
