# Mini Catalog

Тестовое задание на React: мини-каталог товаров с карточкой товара и корзиной.

Данные берутся из `src/services/api.js`. Источник данных не менялся, поверх него добавлен тонкий API-адаптер и mapper-слой для нормализации DTO в доменную модель.

## Стек

- `Vite`
- `React 18`
- `TypeScript`
- `React Router`
- `Zustand`
- `shadcn/ui`
- `Vitest` + `Testing Library`

## Запуск

```bash
npm install
npm run dev
```

Дополнительно:

```bash
npm run test
npm run build
```

## Что реализовано

- 3 страницы: каталог, карточка товара, корзина
- список товаров с изображением, названием и ценой
- поиск по названию
- фильтр `в наличии`
- сортировка по минимальной цене товара
- переход из каталога в карточку товара
- галерея изображений на странице товара без сторонних библиотек
- выбор цвета и размера
- блокировка недоступных размеров
- добавление в корзину по схеме `товар + цвет + размер`
- изменение количества и удаление позиций в корзине
- сохранение корзины в `localStorage`
- отображение количества товаров и суммы прямо в кнопке перехода в корзину
- общая сумма по корзине
- состояния `loading / error / empty / notFound`
- экран `Товар не найден` со ссылкой назад

## Что сделано дополнительно

- состояние фильтров каталога сохраняется в URL
- `color` и `size` на странице товара сохраняются в URL
- отдельный UX-сценарий для товара, который существует, но недоступен для покупки
- промокоды в корзине:
  - `SALE10` — скидка 10%
  - `MINUS300` — скидка 300 ₽

## Исходное задание

### Задача

Реализовать мини-каталог товаров на React.

Данные о товарах нужно получать из псевдо-API, которое находится тут - `src/services/api.js`

Нужно сделать 3 страницы:

1. Список товаров
2. Детальная страница товара
3. Корзина

Выбор библиотек для реализации страниц не ограничен.

Вёрстка и стилизация не является ключевым фактором - важнее корректность, структурность, чистота реализации.

### Требования

#### 1) Список товаров

- Показать товары с картинкой, названием и ценой
- По клику на товар - переход на карточку товара
- Реализовать поиск, фильтры, сортировку:
  - поиск по названию
  - фильтр "в наличии"
  - сортировка по цене `asc` / `desc`

#### 2) Карточка товара

- Вывести информацию о товаре
- Просмотр изображений через переключение без использования сторонних библиотек
- Реализовать выбор цвета
- Реализовать выбор размера
- Недоступные размеры для выбранного цвета должны быть заблокированными
- Добавление в корзину по кнопке в количестве одной штуки
- Если товара нет - показать экран "Товар не найден" + ссылка назад

#### 3) Корзина

- Кнопка перехода в корзину должна быть на каждой странице
- Вывод суммы количества добавленных товаров и их стоимости в кнопку перехода на страницу корзины
- Корзина хранит уникальные позиции в связке `продукт + цвет + размер`
- Корзина должна сохраняться в `localStorage`
- Поддержка изменения количества и удаления позиций
- На странице показывать список позиций и общую сумму

#### 4) UX

- Не должно быть runtime-ошибок в обычных сценариях
- При переходах и действиях должны быть адекватные состояния: загрузка, ошибка, пусто и т.д.

### Плюсом

- Состояние `color` и `size` в URL
- Промокод в корзине
